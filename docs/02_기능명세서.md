# 1. MVP 구현 범위

새봄은 자립준비청년이 **목돈 관리부터 자립 준비, 지원제도 안내, 금융사기 예방까지** 한 곳에서 해결할 수 있도록 만든 AI 금융 코치입니다.

회원가입이나 설치 없이 웹에서 바로 이용할 수 있으며, 사용자 정보를 입력하지 않아도 예시 데이터를 통해 전체 기능을 체험할 수 있습니다.

| 구분     | 구현 기능                       |
| ------ | --------------------------- |
| 홈      | 자립 준비도, 오늘의 브리핑, 잔액·현금흐름 요약 |
| 자립 준비  | 5개 영역별 준비도 점검 및 AI 코칭       |
| 현금흐름   | 24개월 잔액 변화 및 소진 시점 확인       |
| 목돈 관리  | 비상금·생활비·저축 배분 및 시뮬레이션       |
| 위험 스캐너 | 문자·계약서·스크린샷의 금융사기·위험요소 검사   |
| AI 코칭  | 사용자의 상황을 반영한 금융·자립 상담       |
| 신뢰성 검증 | AI가 잘못된 금액을 만들어내지 않는지 직접 검증 |

# 3. 사용자 이용 흐름

## 3-1. 첫 방문

**URL 접속 → 문제 정의 확인 → 예시 데이터로 체험 → 홈 대시보드 → 원하는 기능 선택**

별도의 회원가입이나 본인인증 없이 바로 이용할 수 있으며, 예시 사용자 **'김새봄'**의 데이터를 통해 서비스 전체 기능을 확인할 수 있습니다.

—

## 3-2. 현금흐름 예측

**홈 → 현금흐름 예측**

1. 현재 잔액과 수입·지출을 기준으로 24개월 현금흐름 확인
2. 잔액이 바닥나는 시점 확인
3. AI가 현재 상황에서 바꿔볼 수 있는 시나리오 제안
4. 시나리오별 결과를 기존 상황과 비교
5. 필요하면 대화형 코칭 또는 목돈 배분으로 이동

—

## 3-3. 위험 스캐너

**홈 → 위험 스캐너**

1. 문자·카톡·계약서 붙여넣기 또는 스크린샷 업로드
2. 검사 실행
3. 위험 등급 및 위험도 확인
4. 위험 문구를 원문에서 직접 확인
5. 위험 이유와 즉시 행동요령 확인

스크린샷은 이미지 속 내용을 읽은 후 동일한 방식으로 위험 여부를 검사합니다.

—

## 3-4. 목돈 배분 시뮬레이터

**홈 → 배분 시뮬레이터**

1. 현재 보유 금액을 기준으로 기본 배분안 확인
2. 비상금·생활비 금액 조정
3. 저축 금액과 버틸 수 있는 기간 확인
4. 원하는 배분안 저장
5. 필요하면 AI에게 배분 결과에 대한 의견 요청

---

## 3-5. 대화형 코칭

**홈 또는 대화 화면 → 질문 입력**

1. 사용자가 자유롭게 질문
2. 사용자의 현재 상황을 반영해 답변
3. 필요한 경우 관련 정보 카드 제공
4. 지원제도 등 공식 정보가 필요한 경우 출처와 확인 방법 안내
5. 관련 기능으로 바로 이동

# 4. AI 적용 방식

## 4-1. AI가 하는 일

새봄에서 AI는 **숫자를 계산하는 역할보다 사용자의 상황을 이해하고 다음 행동을 제안하는 코치 역할**을 합니다.

| 역할      | AI의 기능                            |
| ------- | --------------------------------- |
| 대화형 코칭  | 질문을 이해하고 상황에 맞는 설명과 행동 제안         |
| 선제 브리핑  | 지금 먼저 확인해야 할 내용을 우선순위로 제안         |
| 자립 코칭   | 부족한 영역을 개선할 방법과 오늘 할 행동 제안        |
| 시나리오 제안 | 현재 상황에서 바꿔볼 수 있는 선택지 제안           |
| 위험 스캐너  | 문자·이미지의 위험 요소를 찾아 위험 문구와 대응 방법 제시 |

### AI가 계산하지 않는 것

금융에서 중요한 **금액·점수·개월 수는 AI가 임의로 계산하지 않습니다.**

* 잔액 및 현금흐름
* 돈이 바닥나는 시점
* 자립 준비도 점수
* 목돈 배분 금액
* 버틸 수 있는 기간

등은 서비스에서 계산한 결과를 사용합니다.

따라서 AI에게 잘못된 금액을 요구하더라도 실제 화면에 표시되는 계산 결과는 변경되지 않습니다.

# 6. 이용 환경 및 MVP 제한사항

## 6-1. 이용 환경

* Chrome, Edge, Safari, Firefox 최신 버전 지원
* 모바일·데스크톱 웹 이용 가능
* 인터넷 연결 필요
* 스크린샷 업로드 지원: PNG / JPG / WEBP / GIF, 최대 4MB

## 6-2. MVP 제한사항

* 금융계좌와 실시간 연동되지 않으며 잔액·수입·지출은 직접 입력
* 회원가입·로그인이 없어 다른 기기에서는 입력 정보를 다시 설정해야 함
* 대화 내용은 장기 보관하지 않음
* 외부 알림 기능은 제공하지 않음
* 지역별 제도 차이가 있을 수 있어 중요 사항은 공식 창구 확인 필요
* AI가 작성하는 문구는 달라질 수 있으나 금액·점수·개월 수 등 핵심 계산값은 서비스 계산 결과를 사용
* 외부 AI 이용량이 제한되는 경우 일부 AI 기능이 일시적으로 제한될 수 있음

---

## 6-3. 개인정보 보호

새봄은 **익명성을 기본으로 설계**했습니다.

* 회원가입 및 본인인증 없음
* 이름·연락처·이메일·주민등록번호 등 개인 식별정보를 요구하지 않음
* 사용자 입력 정보는 브라우저에 저장
* 실제 이용자 데이터를 서버에 저장하지 않음
* 대화 내용을 장기 보관하지 않음
* 위험 스캐너에 입력한 문자·이미지를 별도로 저장하지 않음

사용자가 자신의 상황을 부담 없이 반복해서 질문할 수 있도록 **'누구인지 밝히지 않아도 도움받을 수 있는 금융 코치'**를 지향합니다.
