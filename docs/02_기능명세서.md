## 1. MVP 구현 범위 *

> 아래는 배포 URL에서 **실제로 동작하는 기능만** 기재했습니다. 미구현 및 향후 구현 예정 기능은 제외했습니다.

### 1-1. 구현 범위 요약

제출한 MVP는 **자립준비청년의 목돈 관리·제도 안내·금융사기 예방**을 하나의 모바일 웹에서 제공하는 **완결된 서비스**입니다. 로그인·설치·본인인증 없이 URL 접속만으로 전 기능을 사용할 수 있습니다.

| 구분 | 구현 범위 |
| --- | --- |
| **화면** | 6개 — 홈(대시보드) / 대화 / 위험 스캐너 / 현금흐름 예측 / 배분 시뮬레이터 / 신뢰성 검증. 부가로 내 정보 입력 패널(슬라이드 오버레이) |
| **서버 API** | 6개 — 대화 스트리밍, 위험 검사, 현금흐름 시나리오, 브리핑·코칭, 데모 프로필 조회, RAG 색인 |
| **결정적 규칙엔진** | 4종 — 현금흐름 예측(24개월), 자립 준비도(5축 가중 채점), 목돈 배분(비상금 6개월·생활비 3~6개월), 배분 시뮬레이터 진단. **모두 AI 없이 동작** |
| **생성형 AI** | 5개 역할 — 대화 코칭, 선제 브리핑, 준비도 코칭, what-if 시나리오, 위험 판정(멀티모달) |
| **RAG** | 공식 근거 문서 33건 색인 완료, 벡터 검색으로 답변 근거 주입 및 출처 표기 |
| **데이터베이스** | Supabase PostgreSQL + pgvector — 근거 문서, 데모 프로필 2건 |
| **검증** | 신뢰성 검증 페이지 — 환각 차단 퍼징(실시간 재계산), 적대적 프롬프트 실측, RAG 정확도, 사기탐지 평가셋 결과 공개 |

### 1-2. 구현 범위에 포함되는 항목

- 사용자 프로필 입력·저장·복원 (브라우저 localStorage, 익명)
- 데모 프로필 DB 조회 및 화면 반영
- AI 선제 브리핑 및 규칙 기반 자동 폴백
- 자립 준비도 5축 채점 + 레이더 차트 시각화 + AI 코칭
- 24개월 현금흐름 예측 + 소진 시점 산출 + AI what-if 시나리오 다중 곡선 비교
- 목돈 배분 규칙 계산 + 슬라이더 조정 + 실시간 규칙 기반 진단
- 위험 스캐너 — 텍스트 검사, **스크린샷 이미지 검사(멀티모달)**, 위험 문장 하이라이트
- 대화형 코칭 — 스트리밍 응답, 도구 호출 기반 카드 6종 삽입
- 신뢰성 검증 페이지 — 서버 실시간 퍼징 및 측정 결과 공개
- 장애 대응 — AI 실패 시 규칙 기반 폴백, 모델 할당량 소진 시 자동 전환, DB 장애 시 기능 축소 동작

### 1-3. 구현 범위에서 제외되는 항목 (본 명세 대상 아님)

- 오픈뱅킹·마이데이터 연동을 통한 잔액 자동 반영 (현재는 사용자 직접 입력)
- 카카오 알림톡 등 외부 푸시 알림
- 대화 이력의 서버 영구 저장 (현재 설계상 저장하지 않음)
- 회원 가입·로그인 및 개인 식별 인증
- 상담사 실시간 연결

## 2. 주요 기능 목록 *

> 실제 동작하는 기능만 기능 단위로 작성했습니다. 관련 화면은 배포 URL 기준 경로와 화면명을 함께 표기했습니다.

### 2-1. 핵심 기능

| # | 기능명 | 기능 설명 | 관련 화면 | 구현 상태 |
| --- | --- | --- | --- | --- |
| 1 | **오늘의 선제 브리핑** | 홈 진입 시 프로필·현금흐름·준비도를 종합해 AI가 오늘 챙길 항목 3~4개를 우선순위대로 생성. 각 항목은 tone(정보/주의/위험)과 이동 대상을 가지며, 누르면 해당 기능으로 이동하거나 1인칭 질문이 대화에 자동 입력됨. AI 실패 시 규칙 기반 브리핑으로 자동 대체 | `/` 홈 — '새봄이 오늘 챙긴 N가지' | **구현 완료** |
| 2 | **자립 준비도 5축 채점** | 주거·소득·비상금·지출관리·제도활용을 0~100점으로 규칙 채점하고 가중 평균으로 종합점수 산출. 레이더(오각형) 차트로 시각화하고 가장 약한 축을 지목. **AI가 아니라 규칙엔진이 채점** | `/` 홈 — 자립 준비도 패널 | **구현 완료** |
| 3 | **자립 준비도 AI 코칭** | 규칙엔진이 지목한 최약축을 어떻게 올릴지 AI가 2문장 이내 조언과 '오늘 할 작은 행동' 1개를 제시. 버튼을 누르면 관련 질문이 대화로 이어짐. **AI는 점수를 다시 매기지 않음** | `/` 홈 — 준비도 패널 하단 | **구현 완료** |
| 4 | **24개월 현금흐름 예측** | 현재 잔액에서 시작해 월 수입 + 자립수당 − 월 지출을 24개월간 누적 계산, 잔액이 0 아래로 내려가는 **소진 시점**을 산출. SVG 다중 곡선 차트로 표시 | `/` 예측 화면 | **구현 완료** |
| 5 | **AI what-if 시나리오** | AI가 이 사람이 실제로 손댈 수 있는 변화(취업·주거비 절감·제도 신규 신청 등) 2~3개를 **금액이 아닌 변화량(delta)** 으로 제안. 앱이 각 시나리오의 곡선을 계산해 기준선 위에 겹쳐 표시하고 소진 시점 변화를 비교 | `/` 예측 화면 | **구현 완료** |
| 6 | **위험 스캐너 (텍스트)** | 붙여넣은 문자·카톡·링크·계약서를 AI가 검사해 위험도 0~100, 등급(위험/주의/안전), 위험 문구 원문 발췌, 판단 근거, 즉시 행동요령을 반환. 발췌된 문구는 원문에서 **직접 하이라이트** | `/` 스캐너 화면 | **구현 완료** |
| 7 | **위험 스캐너 (스크린샷·멀티모달)** | 캡처 이미지(PNG·JPG·WEBP·GIF, 4MB 이하)를 드래그앤드롭 또는 `Ctrl+V`로 올리면, AI가 이미지 속 글자를 판독한 뒤 동일한 위험 판정을 수행. 판독된 원문 위에 하이라이트 표시 | `/` 스캐너 화면 | **구현 완료** |
| 8 | **목돈 배분 규칙 계산** | 보유 금액을 비상금(월지출×6개월) → 생활비(재직 3개월 / 미취업 6개월) → 저축 순으로 배분. 총액 부족 시 비율대로 축소. **항목 합계는 항상 총액과 일치** | `/` 시뮬레이터 화면, 대화 카드 | **구현 완료** |
| 9 | **배분 시뮬레이터 (슬라이더)** | 비상금·생활비를 10만 원 단위 슬라이더로 조정하면 저축이 자동 계산되고, 세그먼트 바와 '소득 없이 버틸 수 있는 개월 수'가 실시간 갱신. 규칙 기반 진단 문구가 즉시 표시(AI 호출 없음). 저장 시 배분이 프로필에 반영되고 AI에게 검토 질문이 자동 전달 | `/` 시뮬레이터 화면 | **구현 완료** |
| 10 | **대화형 AI 코칭 (스트리밍)** | 무엇이든 자유롭게 질문. NDJSON 이벤트 스트림으로 텍스트가 실시간 출력되며, 필요 시 AI가 도구를 호출해 카드가 대화 중간에 삽입됨. 대화 맥락과 사용자 프로필을 함께 반영 | `/` 대화 화면 | **구현 완료** |
| 11 | **도구 호출 기반 카드 생성** | AI가 `show_allocation` · `show_forecast` · `show_readiness` · `show_timeline` · `show_risk` 도구를 호출하면 **서버가 사용자 프로필로 직접 계산해** 카드를 생성. AI가 넘긴 금액 인자는 전량 폐기. 답변당 최대 2개로 제한 | `/` 대화 화면 | **구현 완료** |
| 12 | **RAG 근거 검색 및 출처 표기** | 질문을 768차원으로 임베딩해 pgvector 코사인 유사도 검색. 임계값(0.35~0.4)을 넘는 공식 문서만 프롬프트에 주입하고, 답변은 출처 이름을 언급. 근거가 약하면 무리해서 쓰지 않고 공식 창구 안내로 대체 | 대화 / 스캐너 / 예측 / 브리핑 (백엔드 공통) | **구현 완료** |
| 13 | **신뢰성 검증 페이지** | 환각 차단 퍼징을 **페이지 요청 시마다 서버에서 실시간 재계산**해 결과 공개(144케이스). 적대적 프롬프트 실측 기록과 사기탐지 평가셋 19건의 케이스별 판정 결과를 표로 제공 | `/verify` | **구현 완료** |

## 3. 사용자 이용 흐름 *

### 3-1. 첫 방문 흐름 (심사자가 URL 접속 시 그대로 재현되는 흐름)

```
① 배포 URL 접속
   → 로그인·설치·본인인증 없음. 즉시 홈 화면 진입

② 문제 정의 인트로 확인
   → "열여덟에 홀로 서면서 1,000만원을 처음 손에 쥡니다"
   → 정부·공공 통계 3종(연 2,000명 / 68.2% / 46.5%)과 출처 링크 노출
   → 서비스 원칙(계산은 앱, 판단은 AI) 안내 배지

③ 예시 데이터로 화면 자동 미리보기
   → 프로필이 없으므로 가상 인물 '김새봄'의 데이터로 전 기능이 자동으로 채워짐
   → 상단에 "아래는 김새봄님(예시)의 화면이에요" 배너가 상시 표시 (저장되지 않음)

④ 홈 대시보드 확인
   → 자립 준비도 레이더 차트 + 종합점수 + 최약축 지목 + AI 코칭
   → '새봄이 오늘 챙긴 N가지' — AI 선제 브리핑 (누르면 해당 기능으로 이동)
   → 보호종료 D-day / 현재 잔액 / 정착금 / 월 수지 요약
   → "지금 흐름이면 OOOO년 O월에 잔액이 바닥나요" 경고 배너
   → '바로 쓰기' — 현금흐름 예측 / 배분 시뮬레이터 / 위험 스캐너 / 지원제도 찾기

⑤ 원하는 기능으로 이동 (아래 3-2 ~ 3-5 참조)

⑥ 언제든 헤더 🌱 새봄 로고 또는 '← 홈' 버튼으로 홈 복귀
   헤더 🔒 신뢰성 검증 버튼으로 /verify 이동
```

### 3-2. 현금흐름 예측 흐름

```
홈 → '바로 쓰기'의 📉 현금흐름 예측 (또는 소진 경고 배너 클릭)
  → ① 곡선이 즉시 표시 (AI를 기다리지 않고 규칙엔진이 먼저 계산)
       현재 잔액 / 월 수지 / 바닥나는 때 3개 지표
  → ② "새봄이 시나리오를 찾고 있어요" 로딩 표시
  → ③ AI 시나리오 도착 → 기준선 위에 대안 곡선 2~3개가 겹쳐 표시
       각 곡선의 라벨(예: "월세 줄이면", "알바 늘리면")과 근거 한 줄
       AI 인사이트 문장 표시
  → ④ [새봄에게 물어보기] 클릭 시 현재 상황이 반영된 질문이 대화로 자동 전달
       [목돈 배분 조정하기] 클릭 시 시뮬레이터로 이동
```

### 3-3. 위험 스캐너 흐름

```
홈 → '바로 쓰기'의 🛡️ 위험 스캐너
  → ① 아래 셋 중 하나로 검사 대상 입력
       (a) 텍스트 붙여넣기
       (b) [📷 스크린샷 올리기] 또는 드래그앤드롭 또는 Ctrl+V 로 이미지 첨부
       (c) [예시 붙여넣기] 버튼으로 통장대여 사기 예시 문장 자동 입력
  → ② [검사하기] 클릭
  → ③ 검사 중 표시
       (이미지인 경우 "스크린샷의 글자를 읽고 있어요…")
  → ④ 결과 카드 표시
       위험 등급(위험/주의/안전) + 위험도 0~100 게이지
       원문 위에 위험 문구 직접 하이라이트 (문구별 이유 표시)
       판단 근거 목록
       지금 할 행동 목록 (필요 시 금감원 1332 · 경찰 112 안내)
```

### 3-4. 배분 시뮬레이터 흐름

```
홈 → '바로 쓰기'의 💰 배분 시뮬레이터
  → ① 보유 금액 기준으로 규칙 기본 배분이 미리 채워짐
       (비상금 6개월치 → 생활비 → 나머지 저축)
  → ② 비상금·생활비 슬라이더를 10만 원 단위로 조정
       세그먼트 바, 저축 금액, '소득 없이 버틸 개월 수'가 실시간 갱신
       규칙 기반 진단 문구가 즉시 표시 (AI 호출 없이 즉각 반응)
  → ③ 저장하면 배분이 프로필에 반영되고, 이 배분이 적절한지 묻는 질문이
       대화로 자동 전달되어 AI 검토 의견을 받음
```

### 3-5. 대화 흐름

```
홈 또는 대화 화면 하단 입력창에 자유 질문 입력 → 전송
  → ① 질문이 임베딩되어 공식 근거 문서 검색 (RAG)
  → ② 근거 + 사용자 프로필 + 시스템 프롬프트가 AI에 전달
  → ③ 답변이 실시간 스트리밍으로 한 글자씩 출력
  → ④ 필요 시 AI가 도구를 호출 → 서버가 프로필로 계산한 카드가 대화 중간에 삽입
       (배분 카드 / 현금흐름 카드 / 준비도 카드 / 타임라인 카드 / 위험 카드)
  → ⑤ 답변 하단에 공식 창구 안내 상시 표시
```

### 3-6. 내 정보 입력 흐름

```
헤더 우측 '내 정보' 버튼 클릭 (또는 인트로의 [내 정보로 시작하기])
  → 슬라이드 패널에서 입력
       상태: 닉네임 / 보호종료(예정)일 / 주거 상태(7개 선택지) / 근로 상태(5개 선택지)
             / 월 수입 / 월 지출
       재정: 자립정착금 / 자립수당(월) / 현재 잔액
  → 입력 즉시 브라우저 localStorage에 저장 (서버 전송 없음)
  → 패널을 닫으면 홈의 준비도·브리핑·현금흐름이 입력값 기준으로 재계산
  → 재방문 시 자동 복원
  → [DB에서 불러오기] 로 데모 프로필을 불러올 수도 있음
```

## 4. AI 및 데이터 처리 방식 *

### 4-1. AI가 수행하는 역할

**사용 모델**

| 구분 | 모델 | 비고 |
| --- | --- | --- |
| 주 LLM | Google Gemini (`gemini-3.5-flash` 계열 다중 모델 회전) | 기본 설정 |
| 대체 LLM | Anthropic Claude | 환경변수 `LLM_PROVIDER` 하나로 교체, 코드 변경 없음 |
| 임베딩 | Gemini 임베딩 모델, **768차원** | RAG 검색용 |

**AI의 역할 5가지**

| # | 역할 | AI가 하는 일 | AI가 하지 않는 일 |
| --- | --- | --- | --- |
| 1 | 대화형 코칭 | 질문 이해, 눈높이 설명, 다음 행동 제안, 카드 도구 호출 결정 | 금액·잔액·개월 수 계산 |
| 2 | 선제 브리핑 | 오늘 챙길 항목 3~4개 선별, 우선순위·톤·이동 대상 결정 | 새 숫자 생성 (주어진 값만 인용) |
| 3 | 준비도 코칭 | 최약축 개선 방법과 오늘 할 작은 행동 제시 | 점수 채점 |
| 4 | what-if 시나리오 | 손댈 수 있는 변화 2~3개를 **변화량**으로 제안 | 잔액 곡선·소진 시점 계산 |
| 5 | 위험 판정 | 이미지 글자 판독, 위험 문구 원문 발췌, 위험도 산정, 행동요령 작성 | (판정 자체가 AI의 역할) |

**AI가 절대 하지 않는 일 — 환각 차단 구조**

화면에 표시되는 모든 금액·점수·개월 수는 **결정적 규칙엔진**이 계산합니다.

| 계산 대상 | 담당 모듈 | 규칙 |
| --- | --- | --- |
| 24개월 잔액 곡선 · 소진 시점 | `forecast.ts` | 월별 누적: 이전 잔액 + (수입 + 자립수당 − 지출) |
| 자립 준비도 5축 점수 | `readiness.ts` | 축별 규칙 채점 후 가중 평균 (비상금·지출관리 1.2 / 주거·소득 1.0 / 제도활용 0.8) |
| 목돈 배분 금액 | `budget.ts` | 비상금 = 월지출×6, 생활비 = 월지출×(재직 3 / 미취업 6), 나머지 저축 |
| 버틸 수 있는 개월 수 | `simulator.ts` | (비상금 + 생활비) ÷ 월지출 |

AI가 카드를 그리려면 도구를 호출해야 하며, **서버는 도구 이름만 받아들이고 AI가 넘긴 금액 인자는 전부 폐기한 뒤 사용자 프로필로 다시 계산**합니다. 생성된 카드는 화면에 그려지기 전 스키마 검증을 통과해야 하며, 어긋나면 폐기됩니다.

**적용 기법**

- **구조화 출력** — 비대화형 응답은 전부 JSON 스키마로 강제. 표준 JSON Schema 한 벌로 Gemini(`responseJsonSchema`)와 Claude(도구 `input_schema`)를 동시 지원
- **도구 호출** — 대화 중 카드 삽입 (답변당 최대 2개)
- **RAG** — 유사도 임계값 0.35~0.4를 넘는 문서만 주입, 근거 사용 시 출처 표기
- **멀티모달** — 스크린샷을 base64로 전달, 글자 판독과 위험 판정을 1회 호출로 처리
- **스트리밍** — NDJSON 이벤트 스트림으로 텍스트·카드를 순서대로 전송
- **폴백** — AI 실패·시간 초과 시 규칙 기반 결과로 자동 대체
- **안전 프롬프트** — 투자 권유·특정 상품 판매·법률 확정 판단 금지, 불확실 시 공식 창구(1397·1332·112) 안내 강제

### 4-2. 사용 데이터와 입력·출력

| 기능 | 입력 데이터 | 처리 | 출력 데이터 |
| --- | --- | --- | --- |
| 선제 브리핑 | 사용자 프로필, 규칙엔진이 계산한 현금흐름·준비도, RAG 근거 | AI가 우선순위 선별 | 인사말, 브리핑 항목 3~4개(톤·제목·설명·이동대상) |

| 준비도 코칭 | 위 채점 결과, RAG 근거 | AI가 개선 방법 작성 | 조언 2문장, 오늘의 행동 1개, 후속 질문 |

| what-if 시나리오 | 위 계산 결과 요약, 주거·근로 상태, RAG 근거 | AI가 변화량 제안 → 앱이 곡선 재계산 | 시나리오 2~3개(라벨·근거·수입/지출/일시금 변화량), 인사이트 |
| 목돈 배분 | 잔액(또는 정착금), 월 지출, 근로 상태 | 규칙 계산 (AI 미개입) | 비상금·생활비·저축 금액, 사유 |
| 위험 스캐너 | 사용자가 붙여넣은 텍스트 또는 스크린샷 이미지, RAG 근거 | AI가 판독·판정 | 등급, 위험도 0~100, 판독 원문, 위험 문구 발췌 배열, 근거, 행동요령 |
| 대화 | 대화 이력, 사용자 프로필, RAG 근거 | AI가 답변 생성 및 도구 호출 | 스트리밍 텍스트, 서버 계산 카드 |
| RAG 검색 | 사용자 질문 텍스트 | 768차원 임베딩 → pgvector 코사인 유사도 검색 | 상위 3~4건 문서(출처·제목·본문·URL·유사도) |

### 4-3. 개인정보 및 민감정보 처리 여부

**결론: 본 MVP는 개인을 식별할 수 있는 정보를 수집·저장하지 않습니다.**

| 항목 | 처리 방식 |
| --- | --- |
| **회원가입·로그인** | **없음.** 이름·연락처·이메일·생년월일·주민등록번호 등 식별정보를 일절 수집하지 않음 |
| **사용자 프로필** | 보호종료일·주거/근로 상태·수입/지출·금액 등은 **사용자 브라우저의 localStorage에만** 저장. 서버로 전송해 저장하지 않으며, 브라우저 데이터를 지우면 함께 삭제됨 |
| **닉네임** | 자유 입력이며 실명일 필요 없음. 저장 위치는 위와 동일(브라우저) |
| **대화 내용** | **저장하지 않음.** 대화 이력은 브라우저 메모리에만 존재하며 새로고침 시 사라짐. 서버·DB에 기록하지 않음 |
| **스캐너 입력(문자·계약서·스크린샷)** | **저장하지 않음.** 판정을 위해 AI API로 전송한 뒤 응답과 함께 폐기. 파일로 기록하거나 DB에 남기지 않음 |
| **데이터베이스 저장 내용** | ① 공식 근거 문서 33건(공개자료) ② 데모용 **가상 인물** 프로필 2건(`is_demo` 표시). **실제 이용자 데이터는 저장되지 않음** |
| **AI API 전송** | 답변 생성을 위해 프로필 요약·질문·검사 대상이 LLM 제공자(Google / Anthropic)로 전송됨. 이는 서비스 제공에 필요한 최소 범위이며, 식별정보가 포함되지 않음 |
| **민감정보** | 건강·사상·정치성향 등 민감정보를 수집하지 않음. 다만 '자립준비청년'이라는 지위 자체가 낙인 요소가 될 수 있다고 판단해, **어디에도 등록하지 않는 익명 구조**를 채택 |
| **쿠키·추적** | 광고·분석용 추적 스크립트 미사용 |

> **설계 의도** — 개인정보를 최소 수집하는 것이 규제 대응 때문만은 아닙니다. 이용자가 "내가 자립준비청년이라는 사실"을 어디에도 남기지 않아야 실제로 쓰기 때문에, **익명성을 접근성의 전제**로 두고 설계했습니다.
>
> **향후 확장 시 고려사항** — 오픈뱅킹·마이데이터 연동이나 상담사 연결로 확장할 경우 개인정보 수집이 불가피하므로, 그 시점에는 별도 동의 절차·암호화 저장·보관기간 정책·접근통제를 갖춰야 합니다. 본 MVP는 해당 기능을 구현 범위에서 제외했습니다.

### 5-4. MVP 단계의 제한사항

**기능적 제한**

1. **금융 계정 미연동** — 잔액·수입·지출은 사용자가 직접 입력합니다. 오픈뱅킹·마이데이터 연동은 구현 범위에서 제외했습니다.
2. **로그인 없음에 따른 제약** — 익명성을 우선했기 때문에 프로필이 브라우저에만 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우면 다시 입력해야 합니다.
3. **대화 이력 미보존** — 대화는 저장하지 않으므로 새로고침 시 사라집니다. 개인정보 보호를 위한 의도적 설계입니다.
4. **알림 미구현** — 신청 마감·잔액 소진 임박 시 외부 푸시 알림은 구현하지 않았습니다. 앱 진입 시 브리핑으로 대체합니다.
5. **지역별 제도 차이 미반영** — 자립정착금은 시·도마다 금액과 요건이 다르나, MVP에서는 전국 공통 정보를 기준으로 안내하고 정확한 금액은 공식 창구 확인을 안내합니다.
