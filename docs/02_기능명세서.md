## 1. MVP 구현 범위*

**서비스명** 새봄 (Saebom) — 자립준비청년을 위한 AI 금융 코치
**배포 URL** https://daker-finance-ai-challenge-2026.vercel.app/

새봄은 자립준비청년이 **목돈 관리부터 자립 준비, 지원제도 안내, 금융사기 예방까지** 한 곳에서 해결할 수 있도록 만든 AI 금융 코치입니다. 회원가입이나 설치 없이 웹에서 바로 이용할 수 있으며, 정보를 입력하지 않아도 예시 인물 '김새봄'의 데이터로 전체 기능이 채워져 있어 즉시 체험할 수 있습니다.

아래 표의 기능은 **모두 배포 URL에서 실제로 동작합니다.**

| 화면 | 구현 범위 |
| --- | --- |
| **홈** | 오늘의 선제 브리핑 3가지, 내 금융 상태(잔액·월 수지·버티는 기간), 자립 준비도 오각형 리포트, 도구 바로가기, 근거 통계와 출처 |
| **현금흐름 예측** | 24개월 잔액 곡선, 소진 시점, AI What-if 시나리오 비교, 곡선 켜고 끄기, 신청 가능한 제도와 그 효과 |
| **목돈 배분 시뮬레이터** | 비상금·생활비·저축 배분 조정, 버티는 기간 실시간 계산, 위험도별 진단 |
| **위험 스캐너** | 문자·카톡·링크·계약서 텍스트 검사, 스크린샷 이미지 검사, 위험 문구 원문 하이라이트 |
| **지원제도 찾기** | 13개 공식 제도를 급한 순서로 정렬, 금액·대상·신청처·전화·출처 확인일 표시 |
| **새봄에게 물어보기** | 상황을 반영한 대화형 코칭, 답변 중 계산 카드 제시 |
| **내 정보** | 프로필 입력, 용도별 배분 직접 입력, 이미 받고 있는 지원 체크 |
| **신뢰성 검증(`/verify`)** | 금액 환각 차단 실측 결과 3종 공개 |

**미구현 및 향후 예정 기능은 이 문서에 포함하지 않았습니다.**

## 3. 사용자 이용 흐름*

### 3-1. 첫 방문

**배포 URL 접속 → 홈 대시보드 → 원하는 도구 선택**

회원가입·본인인증·설치가 없습니다. 정보를 입력하지 않은 상태에서는 예시 인물 **'김새봄'**(잔액 400만 원, 월 수입 40만 원, 월 지출 125만 원)의 데이터로 모든 화면이 채워져 있어 곧바로 전체 기능을 볼 수 있습니다. 우측 상단 **내 정보**에서 본인 값을 넣으면 그 즉시 모든 계산이 사용자 값으로 바뀝니다.

### 3-2. 현금흐름 예측

**홈 → 현금흐름 예측**

1. 현재 잔액·매달 남는 돈·잔액이 바닥나는 때를 확인
2. 24개월 잔액 곡선과 소진 시점 확인
3. AI가 제안한 시나리오(공공임대 이사, 근로시간 확대 등)를 곡선으로 비교
4. 범례를 눌러 보고 싶은 곡선만 남김
5. 아래 **"이걸 신청하면 달라져요"**에서 제도별 효과(`지금 11개월 → 신청하면 24개월+`) 확인
6. **신청 방법 보기** 또는 전화번호로 바로 연결

### 3-3. 목돈 배분 시뮬레이터

**홈 → 목돈 배분 시뮬레이터**

1. 나눌 돈(현재 잔액)과 기본 배분안 확인
2. 비상금·생활비 슬라이더 조정 (저축은 남는 만큼 자동)
3. 조정할 때마다 **수입이 끊겼을 때 버티는 기간**이 즉시 갱신
4. 진단 박스의 색으로 현재 배분의 위험도 확인
5. **이 배분으로 저장하고 새봄에게 물어보기**로 의견 요청

### 3-4. 위험 스캐너

**홈 → 위험 스캐너**

1. 문자·카톡·계약서 붙여넣기, 또는 스크린샷 업로드·붙여넣기(Ctrl+V)
2. **안전한지 확인하기** 실행
3. 위험 등급과 0~100 위험도 확인
4. 위험 문구가 원문 위에 색칠된 것을 직접 확인
5. 위험한 이유와 지금 해야 할 행동 확인

### 3-5. 지원제도 찾기

**홈 → 지원제도 찾기**

1. 지금 급한 순서로 정렬된 제도 목록 확인
2. 거주 지역을 입력하면 지역 전용 제도가 반영
3. 카드에서 금액·대상·신청 방법·전화번호 확인
4. **공식 안내 보기**로 공식 사이트 이동, 또는 **새봄에게 묻기**로 질문

### 3-6. 대화형 코칭

**홈 또는 새봄에게 물어보기 → 질문 입력**

1. 자유롭게 질문 입력
2. 입력한 상황을 반영한 답변 수신
3. 필요한 경우 계산 카드가 답변과 함께 표시
4. 공식 정보가 필요한 경우 출처와 확인 방법 안내
5. 관련 기능으로 바로 이동

## 4. AI 및 데이터 처리 방식*

### 4-1. AI가 수행하는 역할

새봄에서 AI는 **숫자를 계산하는 역할이 아니라, 상황을 이해하고 다음 행동을 제안하는 코치 역할**을 합니다.

| 역할 | AI가 하는 일 |
| --- | --- |
| 선제 브리핑 | 지금 먼저 확인해야 할 내용을 우선순위로 정리 |
| 자립 코칭 | 부족한 영역을 개선할 방법과 오늘 할 행동 제안 |
| 시나리오 제안 | 현재 상황에서 바꿔볼 수 있는 선택지 제안 |
| 위험 스캐너 | 문자·이미지의 위험 문구를 찾아 이유와 대응 방법 서술 |
| 대화형 코칭 | 질문을 이해하고 상황에 맞는 설명과 행동 제안 |

### 4-2. AI가 계산하지 않는 것

다음 값은 **AI가 아니라 서비스의 계산 로직이 산출**하며, AI가 다른 값을 제시해도 화면에는 반영되지 않습니다.

- 잔액 및 24개월 현금흐름 곡선
- 잔액이 바닥나는 시점
- 자립 준비도 점수(5개 영역 및 총점)
- 목돈 배분 금액
- 버티는 기간(개월 수)
- 제도 신청 시 늘어나는 개월 수

**구조** — AI는 카드를 직접 그리지 않고 도구(`show_forecast`, `show_allocation`, `show_readiness`)를 호출만 합니다. 서버는 AI가 넘긴 인자를 버리고 사용자 프로필로 다시 계산한 값만 카드에 넣습니다.

### 4-3. 입력·출력 데이터

| 구분 | 내용 |
| --- | --- |
| **입력(사용자)** | 보호종료(예정)일, 거주 지역, 주거·근로 상태, 월 수입·지출, 자립정착금 총액, 자립수당, 현재 통장 잔액, 용도별 배분, 이미 받고 있는 지원 |
| **입력(AI에게 전달)** | 위 프로필 요약, 대화 내역, 위험 스캐너에 붙여넣은 문자·이미지 |
| **참조 데이터** | 13개 공식 지원제도 정보, 금융감독원 공개 사기 수법, 정부 통계 |
| **출력** | 브리핑 문구, 코칭 답변, 시나리오 제안, 위험 등급·위험 문구·대응 방법, 계산 카드(수치는 서비스 계산값) |

### 4-4. 개인정보 및 민감정보 처리

새봄은 **익명성을 기본으로 설계**했습니다.

- 회원가입·본인인증 없음
- 이름·연락처·이메일·주민등록번호·계좌번호 등 개인 식별정보를 **요구하지 않음** (닉네임은 선택)
- 사용자가 입력한 정보는 **브라우저(localStorage)에만 저장**하며 서버에 보관하지 않음
- 대화 내용을 장기 보관하지 않음
- 위험 스캐너에 입력한 문자·이미지를 별도로 저장하지 않음

### 5-4. MVP 단계의 제한사항

- 금융계좌와 실시간 연동되지 않으며 잔액·수입·지출은 직접 입력
- 회원가입·로그인이 없어 다른 기기에서는 입력 정보를 다시 설정해야 함
- 지원제도는 13개를 광역 시·도 단위로 담았으며, 시·군·구 단위 제도는 아직 포함하지 않음
- 제도 금액·조건은 확인일 기준이며, 변경될 수 있으므로 신청 전 공식 창구 확인 필요
- 외부 알림(문자·푸시) 기능은 제공하지 않음
- 대화 내용은 장기 보관하지 않아 이전 대화를 다시 불러올 수 없음
- AI가 작성하는 **문구**는 매번 달라질 수 있으나, 금액·점수·개월 수 등 **핵심 계산값은 항상 서비스 계산 결과**를 사용
- 외부 AI 사용량이 제한되는 경우 일부 AI 문구가 규칙 기반 문구로 대체될 수 있으며, 이때도 계산 기능은 정상 동작
