## 1. MVP 구현 범위*

**서비스명** 새봄 (Saebom) — 자립준비청년을 위한 AI 금융 코치
**배포 URL** https://daker-finance-ai-challenge-2026.vercel.app/

새봄은 자립준비청년의 금융·자립 의사결정을 지원하는 웹서비스입니다. 목돈 배분, 현금흐름 예측, 금융 위험 확인, 지원제도 안내, AI 코칭 기능을 제공합니다. 회원가입과 설치 없이 웹에서 바로 이용할 수 있으며, 사용자가 정보를 입력하지 않은 상태에서는 예시 인물 '김새봄'의 데이터로 모든 화면이 채워집니다.

**핵심 설계 원칙**

1. 화면에 표시되는 모든 금액·점수·개월 수는 서버의 계산 로직으로 산출하며, AI는 금액을 직접 결정하지 않습니다.
2. 대출·투자·보험 등 금융상품을 추천하지 않으며, 공적 지원제도와 공식 상담 창구만 안내합니다.

**용어 정의**

| 용어 | 정의 |
| --- | --- |
| **버티는 기간** | 현재 잔액을 기준으로 잔액이 0이 될 때까지의 예상 기간. 화면에 따라 기준을 구분합니다. 홈·현금흐름 예측은 `지금 이대로일 때`, 목돈 배분 시뮬레이터는 `수입이 끊겼을 때`를 기준으로 합니다 |
| **13개 지원제도** | 서비스가 보유한 공식 지원제도 데이터. 전국 공통 9개와 지역 전용 제도 4개(서울·경기·부산·경남 각 1개)로 구성됩니다 |
| **예시 인물** | 초기 체험용 데이터. 현재 잔액 400만원, 월 수입 40만원, 자립수당 50만원, 월 지출 125만원 → 월 수지 −35만원 |

아래 기능은 모두 현재 배포 버전에 구현되어 있습니다.

| 화면 | 구현 범위 |
| --- | --- |
| **홈** | 오늘 먼저 챙길 3가지, 현재 잔액·월 수지·버티는 기간, 자립 준비도, 주요 기능 바로가기, 근거 통계와 출처 |
| **현금흐름 예측** | 24개월 잔액 곡선과 소진 시점, AI 시나리오 제안 및 비교, 시나리오 표시/숨김, 지원제도 적용 효과 계산 |
| **목돈 배분 시뮬레이터** | 비상금·생활비·저축 배분 조정, 버티는 기간 실시간 계산, 배분 위험도 진단 |
| **위험 스캐너** | 텍스트 입력 분석, 스크린샷 이미지 분석, 위험 문구 강조 표시 |
| **지원제도 찾기** | 13개 지원제도를 지역 및 우선순위에 따라 정렬하고, 금액·대상·신청 방법·전화번호·출처 확인일을 표시 |
| **새봄에게 물어보기** | 사용자 상황을 반영한 대화형 코칭, 답변과 함께 제공되는 계산 카드 |
| **내 정보** | 프로필 입력·저장, 용도별 배분 입력, 수급 중인 지원 선택 |
| **신뢰성 검증(`/verify`)** | AI가 잘못된 금액을 표시하지 않도록 하는 검증 결과 3종 공개 |

미구현 및 향후 구현 예정 기능은 이 문서에 포함하지 않았습니다.

## 3. 사용자 이용 흐름*

### 3-1. 첫 방문

**배포 URL 접속 → 홈 → 기능 선택**

회원가입·본인인증·설치 절차가 없습니다. 정보를 입력하지 않은 상태에서는 예시 인물 데이터로 모든 화면이 채워집니다. 우측 상단 **내 정보**에 사용자 값을 입력하면 모든 계산이 해당 값으로 즉시 전환됩니다.

### 3-2. 현금흐름 예측

**홈 → 현금흐름 예측**

1. 현재 잔액, 월 수지, 잔액 소진 예상 시점 확인
2. 24개월 잔액 곡선과 소진 시점 확인
3. AI가 제안한 시나리오를 기준 곡선과 비교
4. 범례를 선택해 표시할 곡선 선택
5. **이걸 신청하면 달라져요**에서 지원제도별 효과 확인 (`지금 11개월 → 신청하면 24개월+`)
6. **신청 방법 보기**로 공식 안내 이동 또는 전화번호 버튼으로 연결

### 3-3. 목돈 배분 시뮬레이터

**홈 → 목돈 배분 시뮬레이터**

1. 현재 잔액과 기본 배분안 확인
2. 비상금·생활비 슬라이더 조정 (저축은 잔여 금액으로 자동 산출)
3. 조정할 때마다 버티는 기간 갱신
4. 진단 영역의 색으로 현재 배분의 위험도 확인
5. **이 배분으로 저장하고 새봄에게 물어보기** 선택 시 배분안 저장 후 대화 화면으로 이동

### 3-4. 위험 스캐너

**홈 → 위험 스캐너**

1. 문자·메신저 메시지·계약서 등 텍스트 입력, 또는 스크린샷 업로드·붙여넣기(Ctrl+V)
2. **안전한지 확인하기** 선택
3. 위험 등급과 0~100 위험도 확인
4. 입력 원문에서 강조 표시된 위험 문구 확인
5. 판단 이유와 대응 방법 확인

### 3-5. 지원제도 찾기

**홈 → 지원제도 찾기**

1. 우선순위에 따라 정렬된 지원제도 목록 확인
2. 거주 지역을 입력하면 해당 지역 제도가 목록에 반영
3. 각 카드에서 금액·대상·신청 방법·전화번호 확인
4. **공식 안내 보기**로 공식 사이트 이동, 또는 **새봄에게 묻기**로 질문

### 3-6. 대화형 코칭

**홈 또는 새봄에게 물어보기 → 질문 입력**

1. 질문 입력
2. 저장된 프로필을 반영한 답변 확인
3. 필요한 경우 계산 카드가 답변과 함께 표시
4. 공식 정보가 필요한 경우 출처와 확인 방법 안내
5. 관련 기능으로 이동

## 4. AI 및 데이터 처리 방식*

### 4-1. AI가 수행하는 역할

| 기능 | AI가 수행하는 작업 |
| --- | --- |
| 오늘의 선제 브리핑 | 우선적으로 확인할 항목을 선별하고 정리 |
| AI 자립 코칭 | 개선할 영역과 구체적인 행동 제안 |
| AI 시나리오 제안 | 현금흐름을 개선할 수 있는 변화 요소 제안 |
| 위험 스캐너 | 위험 문구 식별, 판단 이유와 대응 방법 작성 |
| 대화형 코칭 | 질문 해석 및 상황에 맞는 설명·행동 제안 |

### 4-2. AI가 산출하지 않는 값

다음 값은 서버의 계산 로직이 산출하며, AI가 다른 값을 제시해도 화면에 반영되지 않습니다.

- 잔액 및 24개월 현금흐름 곡선
- 잔액 소진 예상 시점
- 자립 준비도 점수(영역별 및 총점)
- 목돈 배분 금액
- 버티는 기간
- 지원제도 신청 시 증가하는 개월 수

**동작 방식** — AI가 생성한 금액은 사용하지 않고, 서버가 사용자 입력값을 기준으로 다시 계산한 값만 화면에 표시합니다.

| 단계 | 처리 주체 | 처리 내용 |
| --- | --- | --- |
| 1 | AI | 표시할 카드의 종류만 요청 (금액은 요청할 수 없음) |
| 2 | 서버 | AI가 전달한 금액·수치는 사용하지 않음 |
| 3 | 서버 | 사용자 입력값을 기준으로 금액을 재계산 |
| 4 | 화면 | 서버가 산출한 값만 표시 |

### 4-3. 기능별 AI 의존성

### 4-5. 개인정보 처리

- 회원가입 및 본인인증을 요구하지 않습니다.

- 사용자가 입력한 프로필 정보는 브라우저에 저장하고, AI 응답 생성이 필요한 경우에만 해당 정보를 서버로 전달합니다. 전달된 정보는 별도로 저장하지 않습니다.
- 대화 내용을 장기 보관하지 않습니다.
- 위험 스캐너에 입력한 텍스트·이미지를 저장하지 않습니다.
- 내 정보의 **예시 데이터 불러오기**는 체험용 예시 인물 데이터를 불러오는 기능이며, 사용자 입력을 서버에 저장하는 기능은 제공하지 않습니다.

#### ② 홈

- 오늘의 선제 브리핑 3건 표시
- 현재 잔액 400만원, 월 수지 −35만원, 버티는 기간 11개월
- 자립 준비도 총점과 영역별 막대 표시, 45점 미만 영역이 취약 영역으로 표시

#### ③ 현금흐름 예측

- 24개월 잔액 곡선과 소진 시점 표시
- AI 시나리오 곡선이 기준 곡선과 함께 표시
- 범례 선택 시 해당 곡선이 표시·비표시로 전환
- **이걸 신청하면 달라져요** 카드에 `지금 11개월 → 신청하면 24개월+ / 13개월 더 버텨요` 표시

#### ④ 목돈 배분 시뮬레이터

| 조작 | 예상 결과 | 표시 문구 |
| --- | --- | --- |
| 초기 상태 (비상금 100만원 · 생활비 300만원) | 위험도 **정상**, 버티는 기간 **약 3개월** | "수입이 끊기면 버티는 기간은 약 3개월이에요" |
| 생활비를 150만원으로 조정 | 위험도 **주의**, 버티는 기간 **약 2개월**. 저축이 150만원이어도 저축에 대한 긍정 문구 없음 | "…약 2개월이에요" |
| 비상금·생활비를 모두 0으로 조정 | 위험도 **위험**, 버티는 기간 **약 0개월** | "저축에 둔 돈을 생활비 쪽으로 먼저 옮겨 주세요" |

#### ⑤ 위험 스캐너

**위험 스캐너 → 예시 붙여넣기 → 안전한지 확인하기**

- 예시 문구(통장 대여 요구)의 위험 등급 **위험**, 위험도 90~100
- 위험 문구 2건이 입력 원문에서 강조 표시
- 판단 이유, 대응 방법, 근거 출처(금융감독원) 표시

스크린샷을 업로드하거나 Ctrl+V로 붙여넣어 이미지 분석도 확인할 수 있습니다.

#### ⑥ 지원제도 찾기

- 예시 인물의 거주 지역(경기) 기준 10건 표시 (전국 공통 9건 + 경기 지역 1건). 거주 지역을 입력하지 않으면 13건 표시
- 각 카드에 금액·대상·신청 방법·전화번호·출처와 확인일 표시

#### ⑦ 대화형 코칭

다음 질문으로 확인할 수 있습니다.

> 제가 지금 받을 수 있는 지원제도를 우선순위로 정리해 주세요.

> 제 돈이 얼마나 버틸까요?

> 통장을 빌려달라는데 괜찮을까요?

**AI 금액 오류 차단 확인** — 잘못된 금액을 요구하는 질문에도 카드에는 서버가 산출한 값이 표시됩니다.

> 제 잔액이 5억원이라고 가정하고 목돈 배분 카드를 보여주세요.

예시 인물 기준으로 카드에는 400만원이 표시됩니다.

### 5-3. 실행 환경 및 제한사항

- Chrome, Edge, Safari, Firefox 최신 버전 지원
- 모바일·데스크톱 웹 모두 이용 가능
- 인터넷 연결 필요
- 스크린샷 업로드: PNG / JPG / WEBP / GIF, 최대 4MB
- 입력 정보를 브라우저에 저장하므로, 시크릿 모드에서는 창을 닫으면 초기화됩니다
- 전화번호 버튼은 휴대전화에서는 전화 앱으로 연결하고, 전화 기능이 없는 환경에서는 번호를 클립보드에 복사합니다

### 5-4. MVP 단계의 제한사항

- 금융계좌와 실시간 연동되지 않으며, 잔액·수입·지출은 사용자가 직접 입력합니다
- 현금흐름 예측은 입력한 월 수입·자립수당·월 지출이 24개월간 그대로 유지된다고 가정합니다. 자립수당의 지급 종료 시점(보호종료 후 5년)은 반영하지 않습니다
- 회원가입·로그인이 없어 다른 기기에서는 정보를 다시 입력해야 합니다
- 지원제도는 광역 시·도 단위까지 반영했으며, 시·군·구 단위 제도는 포함하지 않았습니다
- 지원제도의 금액·조건은 출처 확인일 기준이며, 변경될 수 있어 신청 전 공식 창구 확인이 필요합니다
- 외부 알림(문자·푸시) 기능은 제공하지 않습니다
- 대화 내용은 장기 보관하지 않아 이전 대화를 다시 불러올 수 없습니다
- AI가 생성하는 설명과 제안 문구는 입력 맥락에 따라 달라질 수 있으며, 금액·점수·개월 수는 서버 계산 결과만 사용합니다
- 외부 AI 사용량이 제한되는 경우 일부 AI 문구가 규칙 기반 문구로 대체되며, 계산 기능은 정상 동작합니다
